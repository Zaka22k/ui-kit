# FrostedGlass

Матовая стеклянная панель: размывает то, что лежит за ней, и сохраняет блик, тень по краю и эффекты наведения и нажатия, как у прежнего компонента LiquidGlass (в репозитории его больше нет). Преломления нет. Подходит и как подложка, и как основа для кнопок, полей ввода и панелей.

Размытие это обычный CSS `backdrop-filter: blur() saturate()` (для Safari дополнительно с префиксом `-webkit-`), поэтому компонент работает во всех современных браузерах и не требует SVG-фильтра. Блик и тень по краю это два слоя из CSS `inset box-shadow`: без canvas, масок, карт и картинок. Форму даёт `border-radius` панели, поэтому при смене размера или радиуса ничего не пересчитывается. Вид подобран по прежним маскам LiquidGlass (расхождение по альфе в среднем 0.5–1.4%, подробнее в разделе «Что проверено»).

- Работает в Chrome, Edge, Safari (в том числе iOS) и Firefox. В Safari и Firefox пока проверено только по документации и коду, живая проверка в этих браузерах впереди.
- Браузер без `backdrop-filter` получает полупрозрачную заливку `fallbackTint`.
- Адаптации цвета стекла и текста под фон в компоненте нет: из Lab она вырезана до отдельного решения.

## Файлы

| Файл | Что внутри |
|---|---|
| `FrostedGlass.tsx` | React-компонент |
| `frostedGlassOptions.ts` | Типы параметров, значения по умолчанию (`FROSTED_GLASS_DEFAULTS`), таблица токенов (`FROSTED_GLASS_TOKENS`) |
| `frostedGlassTokens.ts` | Чтение токенов `--fg-*` и слежение за сменой темы |
| `frostedGlassMath.ts` | Чистая математика: списки теней блика и края (`edgeShadows`, `shadowCss`), подобранные константы `EDGE_FIT` |
| `index.ts` | Экспорты папки. Из корня пакета `@ui-kit/components` доступен только компонент `FrostedGlass`; `FROSTED_GLASS_DEFAULTS`, `FROSTED_GLASS_TOKENS`, `edgeShadows` и прочее наружу не экспортируются |

## Быстрый старт

```tsx
import { FrostedGlass } from "@ui-kit/components";

// Подложка
<FrostedGlass width={320} height={160} radius={32}>
  Содержимое
</FrostedGlass>

// Интерактивная панель: свечение и пружина при наведении и нажатии.
// Семантики кнопки у неё нет: для кнопок используйте Button
<FrostedGlass interactive width={200} height={56} radius={28}>
  Подпись
</FrostedGlass>

// Размер по содержимому
<FrostedGlass width="auto" height="auto" radius={18} style={{ padding: "12px 18px" }}>
  Подпись
</FrostedGlass>
```

Любой параметр это и пропс, и CSS-токен. Токен главнее пропса, пропс главнее значения по умолчанию. Размытие, цвет, блик и тень можно держать целиком в стилях темы:

```css
.toolbar {
  --fg-blur: 28px;
  --fg-tint: color-mix(in srgb, var(--material-popover-bg) 35%, transparent);
  --fg-specular-opacity: 0.5;
}
```

## Токены

Названия и значения по умолчанию взяты прямо из `frostedGlassOptions.ts`.

| Токен | Пропс | Тип | По умолчанию |
|---|---|---|---|
| `--fg-width` | `width` | длина 0…5000 | 320 |
| `--fg-height` | `height` | длина 0…5000 | 160 |
| `--fg-radius` | `radius` | длина 0…9999 | 9999 |
| `--fg-blur` | `blur` | длина 0…100 | 20 |
| `--fg-saturation` | `saturation` | число 0…5 | 1.4 |
| `--fg-tint` | `tint` | цвет | rgba(255, 255, 255, 0) |
| `--fg-fallback-tint` | `fallbackTint` | цвет | rgba(255, 255, 255, 0.55) |
| `--fg-tint-opacity` | `tintOpacity` | число 0…1 | нет |
| `--fg-edge-opacity` | `edgeShadowOpacity` | число 0…1 | 0.35 |
| `--fg-edge-width` | `edgeShadowWidth` | длина 1…80 | 8 |
| `--fg-edge-direction` | `edgeShadowDirection` | число 0…1 | 0.65 |
| `--fg-specular-color` | `specularColor` | цвет | #ffffff |
| `--fg-specular-opacity` | `specularOpacity` | число 0…1 | 0.6 |
| `--fg-specular-width` | `specularWidth` | длина 0.5…30 | 2 |
| `--fg-light-angle` | `specularAngle` | угол -720…720 | -110 |
| `--fg-effects` | `interactive` | 0 / 1 | 0 |
| `--fg-glow-hover` | `glowHover` | число 0…1 | 0.25 |
| `--fg-glow-press` | `glowPress` | число 0…1 | 0.6 |
| `--fg-glow-edge` | `glowEdge` | число 0…1 | 1 |
| `--fg-glow-size` | `glowSize` | длина 10…1200 | 160 |
| `--fg-glow-color` | `glowColor` | цвет | #ffffff |
| `--fg-hover-scale` | `hoverScale` | число 0.5…1.5 | 1 |
| `--fg-press-scale` | `pressScale` | число 0.5…1.5 | 1.06 |
| `--fg-bounce` | `bounce` | число 0…1 | 0.6 |
| `--fg-stiffness` | `stiffness` | число 20…2000 | 300 |

Значения токенов вне диапазона ограничиваются (пропсы не ограничиваются). Неверное по типу значение токена считается незаданным, тогда работает пропс.

- **Токены наследуются.** Токен главнее пропса, поэтому токен на предке действует на все `FrostedGlass` внутри него, в том числе на `Button`. Например, `--fg-radius`, `--fg-width` или `--fg-height` на контейнере перепишут радиус и размеры вложенных панелей.
- **Длины пишите с единицей.** Значение `--fg-edge-width: 10` (без `px`) в браузерах с `CSS.registerProperty` считается незаданным, и работает пропс или значение по умолчанию. Голое число принимается только там, где этого API нет.

**Как работают токены**
- При первом использовании каждый токен регистрируется через `CSS.registerProperty` с типом. Поэтому браузер сам считает `calc()`, `rem`, `var()` и `color-mix()`. Там, где API нет, понимаются только числа и `px`.
- Токены читаются синхронно после каждого рендера компонента. Кроме того, перечитываются при смене атрибута у любого предка (`class`, `data-theme`, inline-стиль с пользовательскими свойствами) и при смене системной цветовой схемы, не чаще раза в кадр.
- Не замечается смена токена, вызванная только правилом стилей без смены атрибутов (например, `:hover` у предка). Для такого случая перерисуйте компонент или задавайте токен через `style`.

## Размытие

`blur` это радиус гауссова размытия в px (по умолчанию 20), он и делает стекло матовым. `saturation` возвращает фону цвет, который размытие стирает (по умолчанию 1.4). Большой радиус на больших панелях заметно нагружает видеокарту, особенно в iOS Safari при прокрутке: не ставьте крупные размытые панели на длинные списки.

## Цвет стекла и блика

`tint` красит само стекло, `specularColor` блик по краю (цвет входит в строку теней через `color-mix()`, поэтому подходит любой CSS-цвет или токен), `glowColor` свечение при наведении. Прозрачность `tint` берётся из самого цвета; `tintOpacity` заменяет её. Для акцентных кнопок задайте все три.

## Края: тень и блик

- Тонкий контур 1.4 px одинаков по всему периметру. Мягкая внутренняя тень зависит от света: на стороне лампы она слабее, на противоположной глубже (`edgeShadowDirection`, 0 даёт равномерное кольцо).
- Блик лежит поверх тени. Направление света задаёт `specularAngle`.
- Направленность даёт смещение теней вдоль света: на стороне лампы полоса уже, на противоположной шире. Блик собран из 4 теней (ядро и широкое свечение, каждое на стороне лампы и вполсилы на противоположной), тень из 2 (контур и мягкая часть).
- Внешней тени у панели нет. Если она нужна, задайте `style={{ boxShadow: "..." }}`.

## Наведение и нажатие

С `interactive` (или `--fg-effects: 1`) появляется пятно свечения под курсором, подсвеченный край и пружинная анимация масштаба (`hoverScale`, `pressScale`, `bounce`, `stiffness`). Пружина пишет свойство `scale` прямо в элемент без перерисовки React и отключается при `prefers-reduced-motion`. На сенсорных экранах наведение не включается, нажатие работает.

Панель-подложку оставляйте без `interactive`, она остаётся статичной.

## Ограничения

- **Нет семантики.** Корень это обычный `div` без роли и `tabIndex`. Фокус, клавиатуру и ARIA нужно добавлять самостоятельно или брать готовые компоненты (`Button`, `Switch` и другие). Слои края и свечения скрыты от скринридеров (`aria-hidden`).
- **Контраст текста зависит от фона.** Заливка по умолчанию полностью прозрачна (`rgba(255, 255, 255, 0)`), поэтому читаемость текста на панели определяется тем, что лежит под ней.
- **Особые режимы отображения не учитываются.** Настройки `prefers-contrast`, `prefers-reduced-transparency` и `forced-colors` компонент не читает. В `forced-colors` браузеры отключают `box-shadow`, поэтому слои блика и тени по краю не отображаются.
- **`tintOpacity` и относительные цвета.** Пропс собирает `rgb(from <tint> r g b / <tintOpacity>)` (Chrome 119+, Safari 16.4+, Firefox 128+). В более старых браузерах такая заливка не применяется.

## Оптимизация

- Блик и тень по краю это строки `box-shadow`, их считает `edgeShadows` (несколько умножений, без цикла по пикселям). Нет canvas, PNG, `ResizeObserver` и замера размера для краёв. Размер и радиус панели на них не влияют.
- Строки пересчитываются только при смене `specularAngle`, `specularWidth`, `edgeShadowWidth`, `edgeShadowDirection` или `specularColor` (`useMemo`). Прозрачности, размытие и перетаскивание их не трогают.
- Кэша нет: он был нужен для масок, строки из нескольких чисел считать дешевле.

## Отличия от LiquidGlass

| | LiquidGlass | FrostedGlass |
|---|---|---|
| Преломление | да, только Chromium | нет |
| Размытие | `blur` 0.25 px внутри SVG-фильтра, `fallbackBlur` 24 px вне Chromium | `blur` 20 px, одно значение для всех браузеров |
| Блик и тень по краю | маски на canvas (`mask-image`) | `inset box-shadow`, без карт |
| Удалённые параметры | | `bezel`, `glassHeight`, `ior`, `strength`, `fallbackBlur` |
| Новый параметр | | `fallbackTint` |
| Префикс токенов | `--lg-*` | `--fg-*` |

Два компонента можно использовать на одной странице: токены и внутренние переменные у них разные.

## Что проверено

- Слои края сверены с прежними масками в Chromium на 9 вариантах (таблетка, кнопка, круг, скруглённый и острый прямоугольник, углы света 30°, 90°, 180°, −45°, −110°, толщины блика 1–6 px, ширины тени 4–24 px, направленность 0–1). Без крайнего пикселя среднее расхождение по альфе 0.5–1.4%, у самой толстой настройки (блик 6 px, тень 16 px) 3.6%. Крайний пиксель на дуге отличается: у старой маски он искусственно вдвое тусклее. Блик толще 3 px у самого края немного ярче прежнего.
- В Chromium: подложка, кнопка с `interactive`, размытие через пропс и через токен, размер `auto`. Ошибок консоли нет.
- Типы `.ts` проверены `tsc --strict`; для `.tsx` типов React в окружении нет, поэтому проверена только сборка esbuild.
- Не проверено: Safari и Firefox вживую (в том числе `inset` с отрицательным `spread` и смещением, `color-mix()` внутри `box-shadow`), `fallbackTint` в браузере без `backdrop-filter`.
- Производительность по сравнению с LiquidGlass не измерена: в среде нет GPU, замер ничего не показал. Нужны замеры на настоящем устройстве.
