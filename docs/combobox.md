# ComboBox

Текстовое поле с выпадающим списком вариантов. Режим по умолчанию: выбрать значение из списка или ввести свой текст. Режим `multiple`: выбрать несколько вариантов, они показываются метками в поле. Есть фильтрация, свой рендер пунктов, подгрузка списка порциями (как в `DataGrid`), валидация и работа в формах.

## Параметры

### 1. Общие

| Название параметра    | Тип                                                                 | Описание                                                                                                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `options`             | `readonly T[]`                                                      | Обязательный массив уже загруженных вариантов (строки, объекты или их комбинация). При подгрузке порциями родитель дописывает в него новые варианты.                                                                       |
| `multiple`            | `boolean`                                                           | Режим множественного выбора (см. раздел 2). По умолчанию `false`. Меняет типы `value`, `defaultValue` и `onChange`.                                                                                                        |
| `valueKey`            | `keyof T`                                                           | Ключ объекта опции, используемый как строковое значение (например, `"id"`). Игнорируется для строковых опций.                                                                                                              |
| `labelKey`            | `keyof T`                                                           | Ключ объекта опции, отображаемый пользователю в списке и в поле (например, `"name"`).                                                                                                                                      |
| `getOptionValue`      | `(option: T) => string`                                             | Функция получения значения из опции. Имеет приоритет над `valueKey`.                                                                                                                                                       |
| `getOptionLabel`      | `(option: T) => string`                                             | Функция получения подписи из опции. Имеет приоритет над `labelKey`.                                                                                                                                                        |
| `renderOption`        | `(option: T, state: ComboBoxOptionState) => ReactNode`              | Свой рендер содержимого пункта. В `state` передаются `{ label, value, selected, active, index }`. Галочка выбранного пункта рисуется компонентом сама.                                                                      |
| `filter`              | `boolean \| ((option: T, query: string, label: string) => boolean)` | Фильтрация **загруженных** вариантов по набранному тексту. По умолчанию `true` (подстрока в `label` без учёта регистра). `false` отключает её: так делают, когда поиск выполняет сервер (см. пример 5).                    |
| `onQueryChange`       | `(query: string) => void`                                           | Набранный текст изменился. Вызывается с `""`, когда текст сбрасывается: потеря фокуса, выбор пункта, `Escape`, повторное открытие списка.                                                                                  |
| `label`               | `ReactNode`                                                         | Подпись поля (связывается с `<input>` через `htmlFor`, а со списком — через `aria-labelledby`). Значения `undefined`, `null`, `false` и `""` не рендерятся.                                                                |
| `labelPlacement`      | `"top" \| "start"`                                                  | Положение подписи: `"top"` (по умолчанию, над полем) или `"start"` (слева от поля).                                                                                                                                        |
| `hint`                | `ReactNode`                                                         | Подсказка под полем (связывается через `aria-describedby`).                                                                                                                                                                |
| `error`               | `ReactNode \| boolean`                                              | Ошибка валидации: красная рамка, `aria-invalid="true"`, текст ошибки вместо `hint` (если передан не `boolean`).                                                                                                            |
| `emptyLabel`          | `ReactNode`                                                         | Что показать в списке, когда ничего не найдено. По умолчанию `"Нет вариантов"`. `null` отключает сообщение: тогда список в этом случае не открывается (удобно, если пользователю разрешено вводить свой текст).             |
| `toggleLabel`         | `string`                                                            | Доступное имя кнопки со стрелкой. По умолчанию `"Показать варианты"`.                                                                                                                                                      |
| `disabled`            | `boolean`                                                           | Блокирует поле и кнопки. Поле не отправляется в форме.                                                                                                                                                                     |
| `readOnly`            | `boolean`                                                           | Поле только для чтения: список не открывается, значение не меняется, но остаётся в форме.                                                                                                                                  |
| `name`                | `string`                                                            | Имя поля для формы. Создаёт скрытые `<input type="hidden">` со значением (`id`, а не подпись). В режиме `multiple` — по одному на каждое значение, читайте их через `FormData.getAll(name)`.                                |
| `placeholder`         | `string`                                                            | Подсказка в пустом поле. В режиме `multiple` скрывается, как только выбран хотя бы один вариант.                                                                                                                           |
| `aria-label`          | `string`                                                            | Имя поля и списка, если нет `label`. Если `label` задан, имя списка берётся из него.                                                                                                                                       |
| `className`           | `string`                                                            | CSS-класс корневого контейнера (`div`).                                                                                                                                                                                    |
| `style`               | `CSSProperties`                                                     | Инлайн-стили корневого контейнера (`div`).                                                                                                                                                                                 |
| `ref`                 | `Ref<HTMLInputElement>`                                             | Ссылка на видимый `<input role="combobox">`.                                                                                                                                                                               |
| `...rest`             | `Omit<InputHTMLAttributes<HTMLInputElement>, ...>`                  | Остальные атрибуты `<input>` (`id`, `form`, `onFocus`, `onBlur`, `onKeyDown`, `aria-describedby` и др.). Из типов исключены `value`, `defaultValue`, `onChange`, `type`, `role`, `size`, `children`, `className`, `style`, `multiple`. |

### 2. Значение: один вариант или несколько

| Название параметра | Тип в режиме по умолчанию                    | Тип при `multiple`                                       | Описание                                                                                                                                                                                                                                                                                                                       |
| ------------------ | -------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `value`            | `string`                                     | `readonly string[]`                                      | Управляемое значение.                                                                                                                                                                                                                                                                                                          |
| `defaultValue`     | `string`                                     | `readonly string[]`                                      | Начальное значение (неуправляемый режим). При изменении содержимого пропа или сбросе формы (`reset`) состояние синхронизируется. Массив сравнивается по содержимому, поэтому `defaultValue={["a"]}` прямо в JSX безопасен.                                                                                                       |
| `onChange`         | `(value: string, option: T \| null) => void` | `(values: string[], options: (T \| null)[]) => void`     | Одно значение: вызывается на каждый введённый символ и при выборе из списка. Если текст совпал с подписью опции (без учёта регистра) или опция выбрана, вторым аргументом приходит она, иначе `null`. Много значений: вызывается при выборе, снятии выбора, удалении метки и `Backspace`; `options[i]` относится к `values[i]`. |

В режиме `multiple` произвольный текст не принимается: значением может быть только вариант из списка. Набранный текст служит для фильтрации и сбрасывается после выбора.

### 3. Подгрузка порциями

| Название параметра    | Тип                | Описание                                                                                                                                                                         |
| --------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hasMore`             | `boolean`          | На сервере есть ещё данные.                                                                                                                                                      |
| `loadingMore`         | `boolean`          | Грузится следующая порция: в конце списка показываются кольцо и `loadingLabel`.                                                                                                  |
| `loadMoreError`       | `boolean`          | Подгрузка не удалась: в конце списка появляется строка с `loadMoreErrorLabel` и `retryLabel`. До повтора автоматических запросов нет.                                            |
| `onEndReached`        | `() => void`       | Пользователь подошёл к концу списка (или список короче видимой области): загрузите следующую порцию. Вызывается один раз для данной длины `options`. Им же вызывается повтор.   |
| `endReachedThreshold` | `number`           | За сколько пунктов до конца вызывать `onEndReached`. По умолчанию `5`.                                                                                                           |
| `totalCount`          | `number`           | Всего вариантов на сервере. Только для скринридеров (`aria-setsize`, `aria-posinset`). Без него при `hasMore` размер набора считается неизвестным (`-1`).                         |
| `loadingLabel`        | `string`           | Текст рядом с кольцом. По умолчанию `"Загрузка"`.                                                                                                                                |
| `loadMoreErrorLabel`  | `string`           | Текст ошибки подгрузки. По умолчанию `"Не удалось загрузить"`.                                                                                                                   |
| `retryLabel`          | `string`           | Текст действия повтора. По умолчанию `"Повторить"`.                                                                                                                              |
| `removeLabel`         | `(label: string) => string` | Доступное имя кнопки удаления метки (режим `multiple`). По умолчанию `` `Удалить: ${label}` ``.                                                                         |

### 4. Экспортируемые типы

`ComboBoxProps<T>`, `ComboBoxBaseProps<T>`, `ComboBoxSingleProps<T>`, `ComboBoxMultipleProps<T>`, `ComboBoxOption`, `ComboBoxOptionState` экспортируются из `@ui-kit/components`.

## Быстрый старт

```tsx
import { ComboBox } from "@ui-kit/components";

export default function App() {
  return (
    <ComboBox
      label="Город:"
      placeholder="Введите или выберите город"
      hint="Выберите из списка или впишите свой вариант"
      options={["Москва", "София", "Берлин", "Париж"]}
      defaultValue="София"
      onChange={(value, option) =>
        console.log("Значение:", value, "Опция:", option)
      }
    />
  );
}
```

## Примеры использования

### 1. Работа с массивом объектов (`valueKey` и `labelKey`)

Когда опции представлены объектами, `ComboBox` показывает в поле свойство из `labelKey`, а в `onChange` и форму передаёт идентификатор из `valueKey`. Если пользователь введёт свой текст, не совпадающий ни с одной опцией, `option` будет равен `null`, а `value` — введённой строке.

```tsx
interface City {
  id: string;
  name: string;
  country: string;
}

const cities: City[] = [
  { id: "msk", name: "Москва", country: "Россия" },
  { id: "sof", name: "София", country: "Болгария" },
  { id: "ber", name: "Берлин", country: "Германия" },
];

<ComboBox
  label="Город назначения:"
  options={cities}
  valueKey="id"
  labelKey="name"
  defaultValue="sof"
  onChange={(value, city) => {
    // При выборе Софии: value === "sof", city === { id: "sof", name: "София", ... }
    // При вводе "Варна": value === "Варна", city === null
  }}
/>;
```

### 2. Кастомная отрисовка пунктов (`renderOption`) и собственный фильтр (`filter`)

С помощью `renderOption` можно добавить в строку второстепенную информацию или иконки, а через функцию `filter` — искать сразу по нескольким полям объекта.

```tsx
<ComboBox
  label="Поиск города:"
  options={cities}
  valueKey="id"
  labelKey="name"
  filter={(city, query) =>
    `${city.name} ${city.country}`.toLowerCase().includes(query.toLowerCase())
  }
  renderOption={(city, { selected }) => (
    <div style={{ display: "flex", justifyContent: "space-between", gap: 12 }}>
      <span style={{ fontWeight: selected ? 600 : 400 }}>{city.name}</span>
      <span
        className="CaptionTextBlockStyle"
        style={{ color: "var(--label-secondary-strong)" }}
      >
        {city.country}
      </span>
    </div>
  )}
/>
```

### 3. Валидация, расположение подписи и управляемый режим

Габариты, стили ошибок и боковое расположение подписи (`labelPlacement="start"`) совместимы с `TextField`.

```tsx
const [cityId, setCityId] = useState("msk");

<ComboBox
  label="Город:"
  labelPlacement="start"
  options={cities}
  valueKey="id"
  labelKey="name"
  value={cityId}
  onChange={(val) => setCityId(val)}
  error={!cityId && "Пожалуйста, укажите город"}
  hint="Начните печатать для фильтрации"
/>;
```

### 4. Множественный выбор (`multiple`)

Выбранные варианты показываются метками в поле. Список остаётся открытым, пункт отмечается галочкой, повторный выбор снимает отметку. Метку можно удалить крестиком или клавишей `Backspace` в пустом поле.

```tsx
const [ids, setIds] = useState<string[]>(["msk"]);

<ComboBox
  multiple
  label="Города маршрута:"
  options={cities}
  valueKey="id"
  labelKey="name"
  value={ids}
  onChange={(values, selected) => {
    setIds(values);
    // selected[i] — объект для values[i], либо null, если его ни разу не загружали
  }}
/>;
```

В форме каждое значение отправляется отдельным полем:

```tsx
<form action={save}>
  <ComboBox multiple name="city" options={cities} valueKey="id" labelKey="name" />
</form>;

async function save(data: FormData) {
  const ids = data.getAll("city"); // ["msk", "ber"]
}
```

Подписи выбранных вариантов компонент запоминает, поэтому метки не пропадают, когда вариант выпадает из `options` (например, после нового поиска). Если же значение пришло в `defaultValue` / `value` и варианта с таким значением ещё не было ни в одном `options`, на метке будет само значение. Чтобы показать подпись, включите нужный вариант в `options`.

### 5. Подгрузка порциями и поиск на сервере

Принцип тот же, что у `DataGrid`: родитель хранит загруженные варианты и флаги, компонент сообщает через `onEndReached`, что пора грузить следующую порцию.

```tsx
function CityPicker() {
  const [query, setQuery] = useState("");
  const [items, setItems] = useState<City[]>([]);
  const [cursor, setCursor] = useState<string | null>("");
  const [loading, setLoading] = useState(false);
  const [failed, setFailed] = useState(false);

  const load = async (search: string, from: string | null, append: boolean) => {
    setLoading(true);
    setFailed(false);
    try {
      const page = await api.cities({ search, cursor: from }); // { items, next }
      setItems((prev) => (append ? [...prev, ...page.items] : page.items));
      setCursor(page.next);
    } catch {
      setFailed(true);
    } finally {
      setLoading(false);
    }
  };

  return (
    <ComboBox
      label="Город:"
      options={items}
      valueKey="id"
      labelKey="name"
      filter={false} // фильтрует сервер
      hasMore={cursor !== null}
      loadingMore={loading}
      loadMoreError={failed}
      onEndReached={() => load(query, cursor, true)}
      onQueryChange={(text) => {
        setQuery(text);
        load(text, "", false); // новый поиск: список начинается заново
      }}
    />
  );
}
```

Что важно:

- `onEndReached` вызывается один раз для данной длины `options`. Если порция пришла, а конец списка всё ещё близко, он вызовется снова. Если порция не пришла, выставите `loadMoreError`: в конце списка появится строка «Не удалось загрузить — Повторить», её можно выбрать мышью или клавиатурой, и тогда `onEndReached` вызовется ещё раз.
- Новый поиск (`onQueryChange`) должен заменять `options`, а не дописывать их.
- При включённом `filter` (по умолчанию) фильтруются только уже загруженные варианты. Если ничего не совпало, а `hasMore` истинно, компонент будет подгружать следующие порции, пока не найдёт совпадение или не кончатся данные. Для больших наборов используйте поиск на сервере, как выше.
- Выбранное значение, которого нет в загруженных порциях, показывается своим значением (`value`), пока его вариант не встретится в `options`.

### 6. Использование в формах с Server Actions (Next.js / React 19)

При указании `name` компонент рендерит скрытый `<input type="hidden">`, поэтому в `FormData` уходит чистое значение (`id` выбранного пункта или произвольный текст), а не подпись. Во время отправки формы (`useFormStatus`) поле становится нередактируемым и неинтерактивным, но не теряет фокус, а его значение остаётся в форме.

```tsx
<form action={formAction}>
  <ComboBox
    name="city"
    label="Город:"
    options={cities}
    valueKey="id"
    labelKey="name"
    defaultValue={state?.values?.city ?? "sof"}
    error={state?.errors?.city}
  />
  <button type="submit">Сохранить</button>
</form>
```

## Клавиатура и доступность

- Поле имеет `role="combobox"`, `aria-expanded`, `aria-controls` (пока список открыт), `aria-autocomplete` (`"list"`, при `filter={false}` — `"none"`) и `aria-activedescendant`: фокус остаётся в поле, а активный пункт объявляется как виртуальный. Список — `role="listbox"` (с `aria-multiselectable` в режиме `multiple`), пункты — `role="option"` с `aria-selected`. Имя списка берётся из `label` (`aria-labelledby`), если подписи нет — из `aria-label` / `aria-labelledby` поля.
- `ArrowDown` и `ArrowUp` открывают список и перемещаются по пунктам по кругу (при открытии — к выбранному, иначе к первому или последнему). Строка «Повторить» после ошибки подгрузки входит в этот обход.
- `Enter`: при открытом списке выбирает активный пункт (или повторяет подгрузку на строке «Повторить»). Если активного пункта нет, просто закрывает список. В обоих случаях форма **не** отправляется; повторный `Enter` при закрытом списке отправляет форму как обычно. Во время ввода через IME `Enter` игнорируется.
- `Escape`: при открытом списке закрывает его, и событие не доходит до родителей (например, `Modal` не закроется). При закрытом списке очищает набранный текст (в режиме `multiple` метки не трогает); если очищать нечего, событие проходит дальше.
- `Tab` закрывает список и переводит фокус дальше. Потеря фокуса закрывает список и сбрасывает набранный текст.
- Режим `multiple`: `Backspace` в пустом поле удаляет последнюю метку. Кнопки удаления меток и кнопка-стрелка исключены из последовательности `Tab` (`tabIndex=-1`): они нужны для мыши, с клавиатуры всё делается из поля.
- Загрузка и сообщение «нет вариантов» выводятся в области `role="status"`, во время подгрузки у списка стоит `aria-busy`.
- Пункты и метки при `forced-colors: active` различаются без цвета: активный пункт — `Highlight`, выбранный отмечен галочкой, метки имеют рамку.
- Рамка поля, подписи, подсказки и placeholder используют токены с контрастом не ниже `3:1` (рамка) и `4.5:1` (текст): `--control-border`, `--label-secondary-strong`, `--system-red-text`.
- Позиция списка (вниз или вверх) выбирается по его реальной высоте, с учётом полосы прокрутки; прокрутка внутри самого списка позицию не пересчитывает.

## Ограничения

- **Общее пространство значений и произвольного текста (режим по умолчанию):** подпись определяется сверкой текущего `value` со значениями опций (`getOptionValue`). Если пользователь введёт строку, совпадающую с техническим `id` одного из пунктов (например, `"sof"`), после потери фокуса поле заменит её на `label` пункта (`"София"`).
- **`emptyLabel` и свободный ввод:** по умолчанию при вводе текста, которого нет в списке, показывается «Нет вариантов». Если пользователю можно вводить свои значения, передайте `emptyLabel={null}`.
- **Подписи неизвестных значений:** метка или поле показывают само значение, пока вариант с ним ни разу не попадал в `options`. Запомненные подписи живут, пока смонтирован компонент.
- **Обязательность ключей для объектов:** если `options` — объекты, а `valueKey` / `labelKey` и `getOptionValue` / `getOptionLabel` не переданы, значения и подписи будут пустыми строками.
- **Состояние отправки формы:** во время `pending` поле нередактируемое (`readOnly`, `aria-disabled`), а не `disabled`; значение продолжает отправляться через скрытые поля.
- **Стилизация через `className` и `style`:** оба свойства попадают на корневой `div`, а не на `<input>` и не на список (он рендерится порталом в `document.body` со слоем `--ZIndexPopup`).
- **Новые токены темы:** `--control-border`, `--label-secondary-strong` и `--system-red-text` добавлены в тему. Пока их использует только `ComboBox`; `TextField` и другие поля остаются на прежних токенах.
- **Зарезервированные атрибуты:** `type`, `role`, `size`, `multiple` (как атрибут `<input>`) и `children` исключены из типов; режим выбора задаётся пропом `multiple` компонента.
