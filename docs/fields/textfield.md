# TextField

Стандартное текстовое поле ввода с поддержкой подписи (над полем или сбоку), текста подсказки, индикации ошибки валидации, боковых иконок и автоматической блокировки при отправке формы.

## Параметры

| Название параметра | Тип                                                   | Описание                                                                                                                                                             |
| ------------------ | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`            | `ReactNode`                                           | Вводная подпись поля (связывается с `<input>` через `htmlFor`). Значения `null`, `undefined`, `false` и `""` игнорируются.                                           |
| `labelPlacement`   | `"top" \| "start"`                                    | Расположение подписи: `"top"` (по умолчанию, над полем) или `"start"` (перед полем, в одну строку, как в macOS).                                                     |
| `hint`             | `ReactNode`                                           | Вспомогательный текст подсказки под полем ввода (привязывается через `aria-describedby`).                                                                            |
| `error`            | `ReactNode \| boolean`                                | Состояние или текст ошибки валидации. Подсвечивает рамку красным, выставляет `aria-invalid="true"` и выводит текст ошибки вместо `hint` (если передан не `boolean`). |
| `startIcon`        | `ReactNode`                                           | Иконка перед текстовым полем (`18×18px`, наследует `currentColor`). Клик по иконке фокусирует поле.                                                                  |
| `endIcon`          | `ReactNode`                                           | Иконка после текстового поля (`18×18px`, наследует `currentColor`). Клик по иконке фокусирует поле.                                                                  |
| `type`             | `string`                                              | Нативный тип поля `<input>`. По умолчанию `"text"`.                                                                                                                  |
| `disabled`         | `boolean`                                             | Блокирует поле ввода. Поле также автоматически переходит в `disabled`, когда родительская `<form>` отправляется (`useFormStatus`).                                   |
| `id`               | `string`                                              | Пользовательский `id` для `<input>`. Если не указан, генерируется автоматически через `useId()`.                                                                     |
| `className`        | `string`                                              | Пользовательский CSS-класс, применяется к **корневому контейнеру** (`div`), а не к `<input>`.                                                                        |
| `style`            | `CSSProperties`                                       | Инлайн-стили, применяются к **корневому контейнеру** (`div`).                                                                                                        |
| `ref`              | `Ref<HTMLInputElement>`                               | Ссылка, указывающая напрямую на нативный элемент `<input>`.                                                                                                          |
| `...props`         | `Omit<InputHTMLAttributes<HTMLInputElement>, "size">` | Остальные нативные атрибуты `<input>` (`value`, `defaultValue`, `onChange`, `placeholder`, `name` и др.). Нативный атрибут `size` исключён из типов.                 |

## Быстрый старт

```tsx
import { TextField } from "@ui-kit/components";

export default function App() {
  return (
    <TextField
      label="Имя пользователя:"
      placeholder="Введите имя"
      hint="Имя будет видно другим участникам"
      onChange={(e) => console.log(e.target.value)}
    />
  );
}
```

## Примеры использования

### 1. Расположение подписи (`top` и `start`)

По умолчанию подпись располагается над полем (`"top"`). Режим `"start"` выстраивает подпись слева от поля ввода по центру его высоты, при этом подсказка или ошибка остаются строго под самим полем.

```tsx
<TextField label="Имя:" placeholder="Подпись сверху" />

<TextField
  label="Имя:"
  labelPlacement="start"
  placeholder="Подпись слева (macOS-стиль)"
/>
```

### 2. Валидация и вывод ошибок (`hint` и `error`)

Если передать в `error` строку или React-элемент, он заменит собой текст `hint` и перекрасит рамку и сообщение в критический цвет. Если передать `error={true}`, рамка станет красной, но снизу останется текст из `hint`.

```tsx
{
  /* Поле с текстом ошибки вместо подсказки */
}
<TextField
  label="Пароль:"
  type="password"
  hint="Минимум 8 символов, включая цифры"
  error={passwordError} // например: "Пароль слишком короткий"
/>;

{
  /* Только красная рамка с сохранением подсказки */
}
<TextField
  label="Код подтверждения:"
  hint="4 цифры из СМС"
  error={isCodeInvalid} // boolean
/>;
```

### 3. Поле с иконками (`startIcon` и `endIcon`)

Иконки рендерятся внутри области `<label>` самого контрола, поэтому клик по ним или по внутренним отступам автоматически устанавливает фокус в `<input>`.

```tsx
<TextField
  label="Электронная почта:"
  type="email"
  placeholder="name@example.com"
  startIcon={<MailIcon />}
  endIcon={<CheckIcon />}
/>
```

### 4. Работа в формах (Next.js / React 19)

Компонент отслеживает статус родительской формы через `useFormStatus`: во время отправки (`pending`) поле автоматически блокируется без необходимости вручную прокидывать `disabled`.

```tsx
<form action={formAction}>
  <TextField
    label="Город:"
    name="city"
    defaultValue={state?.values?.city}
    error={state?.errors?.city}
  />
  <button type="submit">Сохранить</button>
</form>
```

## Ограничения

- **Нативный атрибут `size` отключён:** Из-за конфликта с дизайн-токенами атрибут `size` исключён из типов. Ширина поля управляется через CSS (`className` или `style`) и по умолчанию подстраивается под базовый размер контрола, не растягиваясь от длинного текста в `hint` или `error`.
- **Стилизация через `className` и `style`:** Оба свойства попадают на внешний корневой `div` (обёртку над подписью, полем и подсказкой), а не на сам `<input>`.
- **Интерактивные иконки:** Так как `startIcon` и `endIcon` обёрнуты в общий тег `<label>` вместе с `<input>`, размещать внутри них отдельные кнопки (`<button>`) не рекомендуется — клик по ним будет перехватываться лейблом и переводить фокус в текстовое поле.
- **Блокировка во время отправки:** Пока форма находится в состоянии `pending`, `<input>` получает нативный `disabled`, поэтому браузер снимает с него фокус.
- **Требуется React 19:** Компонент вызывает `useFormStatus` из `react-dom`, которого нет в React 18.
- **Зависимость от глобальных стилей:** Для корректной типографики и размеров в проекте должны быть подключены глобальные классы `BodyTextBlockStyle`, `CaptionTextBlockStyle` и CSS-токены `--Control*`.
