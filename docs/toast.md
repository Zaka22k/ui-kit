# Toast

Система всплывающих уведомлений, состоящая из контекстного провайдера `ToastProvider` (рендерит тосты через портал в `document.body`) и хука `useToast` для управления очередью уведомлений из любой точки клиентского дерева.

## Параметры

### 1. Свойства `ToastProvider` (`ToastProviderProps`)

| Название параметра | Тип                                             | Описание                                                                                                                                           |
| ------------------ | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`         | `ReactNode`                                     | Дочерние элементы приложения, внутри которых будет доступен хук `useToast`.                                                                        |
| `position`         | `"top-center" \| "top-right" \| "bottom-right"` | Позиция вывода уведомлений по умолчанию. По умолчанию `"top-right"`.                                                                               |
| `duration`         | `number`                                        | Время автоматического показа уведомления в миллисекундах по умолчанию. По умолчанию `5000`.                                                        |
| `limit`            | `number`                                        | Максимальное количество одновременно видимых уведомлений на одну позицию (более старые автоматически закрываются). По умолчанию `5` (минимум `1`). |

### 2. Параметры отдельного уведомления (`ToastOptions`)

| Название параметра | Тип                                                        | Описание                                                                                                                                                  |
| ------------------ | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | `string`                                                   | Пользовательский идентификатор. Если показать тост с уже существующим `id`, он заменит старый тост на месте и перезапустит его таймер.                    |
| `title`            | `ReactNode`                                                | Заголовок уведомления.                                                                                                                                    |
| `description`      | `ReactNode`                                                | Дополнительный поясняющий текст под заголовком.                                                                                                           |
| `variant`          | `"default" \| "info" \| "success" \| "warning" \| "error"` | Визуальный стиль и иконка уведомления (`"default"` рендерится без иконки, `"error"` получает `role="alert"` вместо `"status"`). По умолчанию `"default"`. |
| `duration`         | `number`                                                   | Время показа конкретного тоста в мс. Значение `<= 0` отключает автозакрытие. По умолчанию берётся из `ToastProvider`.                                     |
| `position`         | `"top-center" \| "top-right" \| "bottom-right"`            | Индивидуальная позиция для этого тоста. По умолчанию берётся из `ToastProvider`.                                                                          |
| `dismissible`      | `boolean`                                                  | Отображать ли кнопку-крестик для ручного закрытия. В текущей реализации `ToastItem` по умолчанию `false`.                                                 |
| `action`           | `{ label: ReactNode; onClick: () => void }`                | Кнопка действия внутри уведомления. После клика по ней срабатывает `onClick` и тост автоматически закрывается.                                            |
| `onClose`          | `() => void`                                               | Колбэк, вызываемый в момент начала закрытия тоста (по таймеру, крестику, кнопке действия, вызову `dismiss` или превышению лимита).                        |

### 3. Методы и свойства хука `useToast()` (`ToastApi`)

| Название параметра | Тип                                                                                | Описание                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `show`             | `(input: string \| ToastOptions) => string`                                        | Показывает уведомление (принимает строку-заголовок или объект настроек) и возвращает его `id`.                             |
| `info`             | `(title: ReactNode, options?: Omit<ToastOptions, "title" \| "variant">) => string` | Быстрый вызов уведомления с вариантом `"info"`.                                                                            |
| `success`          | `(title: ReactNode, options?: Omit<ToastOptions, "title" \| "variant">) => string` | Быстрый вызов уведомления с вариантом `"success"`.                                                                         |
| `warning`          | `(title: ReactNode, options?: Omit<ToastOptions, "title" \| "variant">) => string` | Быстрый вызов уведомления с вариантом `"warning"`.                                                                         |
| `error`            | `(title: ReactNode, options?: Omit<ToastOptions, "title" \| "variant">) => string` | Быстрый вызов уведомления с вариантом `"error"`.                                                                           |
| `dismiss`          | `(id?: string) => void`                                                            | Закрывает конкретный тост по `id`, либо закрывает все активные тосты, если вызван без аргументов.                          |
| `position`         | `ToastPosition`                                                                    | Текущая глобальная позиция по умолчанию.                                                                                   |
| `setPosition`      | `(position: ToastPosition) => void`                                                | Изменяет позицию по умолчанию на лету и мгновенно переносит все открытые тосты, у которых не задан собственный `position`. |

## Быстрый старт

Оберните корневой макет приложения в `ToastProvider`:

```tsx
import { ToastProvider } from "@ui-kit/components";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <ToastProvider position="top-right" duration={5000} limit={5}>
      {children}
    </ToastProvider>
  );
}
```

Вызывайте уведомления из любого клиентского компонента через хук `useToast`:

```tsx
"use client";
import { useToast } from "@ui-kit/components";

export function SaveButton() {
  const toast = useToast();

  return (
    <button onClick={() => toast.success("Изменения сохранены")}>
      Сохранить
    </button>
  );
}
```

## Примеры использования

### 1. Различные варианты и подробное уведомление с кнопкой действия

Вы можете использовать короткие методы (`info`, `success`, `warning`, `error`) или метод `show` с полным набором параметров, включая описание, крестик закрытия и кнопку обратного действия. При наведении курсора или фокусе внутри тоста таймер автозакрытия автоматически ставится на паузу.

```tsx
const toast = useToast();

// Короткий вызов ошибки без автозакрытия
toast.error("Ошибка соединения", {
  description: "Проверьте подключение к сети и попробуйте снова.",
  duration: 0,
  dismissible: true,
});

// Тост с кнопкой действия (например, отмена удаления)
toast.warning("Файл перемещён в корзину", {
  description: "Вы можете восстановить его сейчас.",
  dismissible: true,
  action: {
    label: "Отменить",
    onClick: () => restoreFile(),
  },
  onClose: () => console.log("Уведомление закрывается"),
});
```

### 2. Обновление существующего тоста по `id` (индикация загрузки)

Если передать одинаковый `id`, новый вызов не создаст дубликат, а обновит содержимое существующего уведомления, сбросит его анимацию и перезапустит таймер.

```tsx
const toast = useToast();

async function handleUpload() {
  const toastId = "upload-status";

  toast.info("Загрузка файла…", {
    id: toastId,
    duration: 0,
  });

  try {
    await uploadFile();
    toast.success("Файл успешно загружен!", {
      id: toastId,
      duration: 4000,
    });
  } catch {
    toast.error("Не удалось загрузить файл", {
      id: toastId,
      duration: 5000,
      dismissible: true,
    });
  }
}
```

### 3. Управление позицией и программное закрытие

Вы можете задать индивидуальную позицию для отдельного тоста или переключить расположение всех стандартных тостов на лету через `setPosition`.

```tsx
const toast = useToast();

// Показать один тост по центру сверху, независимо от настроек провайдера
toast.show({
  title: "Новое системное сообщение",
  position: "top-center",
});

// Переместить все стандартные тосты в правый нижний угол
toast.setPosition("bottom-right");

// Закрыть все открытые тосты сразу
toast.dismiss();
```

## Ограничения

- **Только внутри `<ToastProvider>` и в Client Components:** Вызов `useToast()` вне провайдера выбросит ошибку `"useToast must be used within <ToastProvider>"`, а сам хук требует директивы `"use client"`. Глобального синглтона для вызова тостов вне React-дерева нет.
- **Кнопка закрытия (`dismissible`) по умолчанию скрыта:** Несмотря на комментарий в интерфейсе `ToastOptions`, в деструктуризации компонента `ToastItem` задано значение по умолчанию `dismissible = false`. Чтобы показать крестик закрытия, нужно явно передать `dismissible: true`.
- **Синхронизация времени анимации выхода:** Константа `EXIT_DURATION = 200` в `Toast.tsx` жёстко привязана к длительности CSS-анимации закрытия (`--toast-duration` / `--ControlAnimationDuration`). При изменении времени в CSS необходимо вручную обновить `EXIT_DURATION`, иначе DOM-элемент будет удаляться раньше или позже завершения анимации.
- **Отсутствие плавной анимации сдвига соседних тостов:** Когда одно из уведомлений в очереди удаляется, соседние тосты занимают его место мгновенно, без layout-анимации скольжения.
- **Запрет на вызов `show` во время рендера:** Методы показа тостов меняют состояние провайдера, поэтому их нужно вызывать только в обработчиках событий или внутри `useEffect`, иначе возникнет бесконечный цикл ререндеров.
