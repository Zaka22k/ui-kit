# List

Коллекция одинаковых элементов в трёх форматах (вертикальный список, сетка, горизонтальная лента) с одиночным выбором, контекстным меню, бесконечной подгрузкой и вашими собственными карточками.

## Свойства

Список ничего не загружает, не сортирует и не фильтрует сам: данные, загрузку, ошибки, поиск и сортировку ведёт родитель, а список показывает переданные `items`. Элементы виртуализированы: в DOM только те, что на экране и рядом с ним. Передайте `aria-label` или `aria-labelledby`.

Из модуля экспортируются `List` (именованный и по умолчанию) и типы `ListProps`, `ListLayout`, `ListItemId`, `ListItemState`, `ListItemMenuTarget`.

### Форматы

| `layout`       | Вид                                                  | Прокрутка                                                                                       | Для чего                                    |
| -------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `"vertical"`   | Один столбец строк. Выбранная строка с плашкой слева | Вместе со страницей; при заданной `height` внутри списка                                        | Текст: контакты, сообщения, журналы         |
| `"grid"`       | Карточки переносятся на несколько столбцов           | Вместе со страницей; при заданной `height` внутри списка                                        | Изображения: галереи, каталоги, библиотеки  |
| `"horizontal"` | Одна строка карточек                                 | Всегда внутри самой ленты (по горизонтали). Может уходить под плавающую панель `NavigationView` | Полки на главной: «Недавние», «Рекомендуем» |

### List

#### Данные и карточки

| Свойство       | Тип                                            | Описание                                                                                                                                                                                       |
| -------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`        | `readonly T[]`                                 | Загруженные на данный момент элементы. При каждом изменении данных передавайте новый массив                                                                                                    |
| `getItemId`    | `(item: T) => string \| number`                | Стабильный уникальный id элемента. К нему привязаны выбор и курсор клавиатуры. Читается при смене `items`, а не при каждом рендере                                                             |
| `renderItem`   | `(item: T, state: ListItemState) => ReactNode` | Рисует содержимое одного элемента (вашу карточку). Вызывается только для элементов на экране и рядом с ним. Содержимое занимает весь элемент и обрезается по его границам. `state` описан ниже |
| `emptyContent` | `ReactNode`                                    | Что показать, когда элементов нет и нечего догружать. По умолчанию «Нет данных»                                                                                                                |

`ListItemState`, второй аргумент `renderItem`:

| Поле       | Тип                                    | Описание                                                                         |
| ---------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| `index`    | `number`                               | Позиция в `items`                                                                |
| `selected` | `boolean`                              | Элемент выбран. Всегда `false`, если `selectable` не включён                     |
| `active`   | `boolean`                              | Курсор клавиатуры на элементе, и список в фокусе (или для элемента открыто меню) |
| `layout`   | `"vertical" \| "grid" \| "horizontal"` | Текущий формат. Позволяет рисовать разное содержимое при переключении формата    |

#### Формат и размеры

Все элементы одного размера. Размеры задаются в px.

| Свойство          | Тип                                    | Описание                                                                                                                                                                    |
| ----------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `layout`          | `"vertical" \| "grid" \| "horizontal"` | Формат элементов. По умолчанию `"vertical"`. При смене формата список прокручивается к началу и забывает курсор клавиатуры                                                  |
| `itemWidth`       | `number`                               | `horizontal`: фиксированная ширина карточки. `grid`: наименьшая ширина, карточки растягиваются на всю строку. `vertical` не использует. По умолчанию `200`                  |
| `itemHeight`      | `number`                               | Высота элемента. По умолчанию `56` для `vertical` и `160` для остальных форматов                                                                                            |
| `itemAspectRatio` | `number`                               | Только `grid`: отношение ширины к высоте карточки. Если задано, высота следует за шириной (при растягивании карточек меняется вместе с ней), а `itemHeight` не используется |
| `columns`         | `number`                               | Только `grid`: фиксированное число столбцов. Без него число столбцов зависит от ширины списка и `itemWidth`                                                                 |
| `gap`             | `number`                               | Промежуток между элементами. По умолчанию `4` для `vertical` и `12` для остальных форматов                                                                                  |

#### Прокрутка

| Свойство | Тип                | Описание                                                                                                                                                                                                                                                               |
| -------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `height` | `number \| string` | `vertical` и `grid`. По умолчанию `"auto"`: список прокручивается вместе со страницей (ближайший предок с `overflow-y: auto` или `scroll`, иначе окно). Число или `"100%"`: список прокручивается внутри себя в контейнере этой высоты. В `horizontal` не используется |
| `bleed`  | `boolean`          | Только `horizontal`. Лента тянется до края окна, и прокрутка уходит под плавающую панель `NavigationView` (`extendContentUnderPane`). По умолчанию `true`. Вне `NavigationView` и `Page` ничего не меняет                                                              |

#### Выбор и действия

Выбирается один элемент. Режим управляемый, когда `selectedId` не `undefined`.

| Свойство            | Тип                                                       | Описание                                                                                                                              |
| ------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `selectable`        | `boolean`                                                 | Разрешить выбор элемента. По умолчанию `false`                                                                                        |
| `selectedId`        | `string \| number \| null`                                | Выбранный id (управляемый режим). `null`: ничего не выбрано                                                                           |
| `defaultSelectedId` | `string \| number \| null`                                | Выбранный id в начале (неуправляемый режим)                                                                                           |
| `onSelectionChange` | `(id: string \| number \| null, item: T \| null) => void` | Выбор изменился. `item` равен `null`, если выбор снят или элемент ещё не загружен. Не вызывается при клике по уже выбранному элементу |
| `onItemClick`       | `(item: T) => void`                                       | Клик по элементу. Вызывается при каждом клике, в том числе по выбранному и при отключённом `selectable`                               |
| `onItemActivate`    | `(item: T) => void`                                       | Двойной клик или `Enter` на элементе с курсором                                                                                       |

Выбор меняется кликом по элементу и клавишей `Space` на элементе с курсором. Чтобы снять выбор, кликните по выбранному элементу или нажмите `Space` на нём с зажатым `Ctrl` (`Cmd` на macOS). Правый клик, после которого открылось контекстное меню, тоже выбирает элемент (если включён `selectable`).

#### Бесконечная подгрузка

| Свойство              | Тип                | Описание                                                                                                                                                                                                                                                                                                                                 |
| --------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hasMore`             | `boolean`          | На сервере есть ещё данные. По умолчанию `false`                                                                                                                                                                                                                                                                                         |
| `loadingMore`         | `boolean`          | Идёт подгрузка: в конце списка кольцо загрузки. По умолчанию `false`                                                                                                                                                                                                                                                                     |
| `loadMoreError`       | `boolean`          | Подгрузка упала: в конце сообщение и кнопка «Повторить», она снова вызывает `onEndReached`. По умолчанию `false`                                                                                                                                                                                                                         |
| `onEndReached`        | `() => void`       | Пора загрузить следующую порцию. Вызывается, когда до конца загруженных элементов осталось не больше `endReachedThreshold` линий, при `hasMore`, без `loadingMore` и `loadMoreError`. Для одного и того же числа загруженных элементов вызывается один раз. Если элементов не хватает, чтобы заполнить видимую область, вызывается сразу |
| `endReachedThreshold` | `number`           | За сколько линий до конца вызывается `onEndReached`. Линия это строка в `vertical`, ряд карточек в `grid`, столбец в `horizontal`. Отсчёт идёт от края отрисованного окна, а оно шире видимой области на запас в несколько линий, поэтому фактически подгрузка стартует чуть раньше. По умолчанию `5`                                    |
| `totalCount`          | `number`           | Всего элементов на сервере, только для скринридеров (`aria-setsize`). Без него при `hasMore` размер набора объявляется как неизвестный                                                                                                                                                                                                   |
| `resetKey`            | `string \| number` | Смените, когда список заменён целиком (поиск, сортировка): список прокрутится к началу, забудет курсор клавиатуры и закроет меню                                                                                                                                                                                                         |

#### Контекстное меню и вид

| Свойство                        | Тип                                                                         | Описание                                                                                                                                                                                                                                                |
| ------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `itemMenu`                      | `(target: ListItemMenuTarget<T>) => ContextMenuItem[] \| null \| undefined` | Пункты контекстного меню элемента (тот же `ContextMenu`, что у `DataGrid`). `target` содержит `item` и `index`. Если ничего не вернуть (или вернуть пустой массив), остаётся меню браузера. Открывается правой кнопкой, `Shift+F10` или клавишей «Меню» |
| `itemAppearance`                | `"default" \| "none"`                                                       | `"default"`: список рисует рамку элемента (наведение, выбор, курсор клавиатуры): строку в `vertical`, карточку в `grid` и `horizontal`. `"none"`: рамки нет, всё рисует ваша карточка. По умолчанию `"default"`                                         |
| `className`, `style`            |                                                                             | Корневой элемент                                                                                                                                                                                                                                        |
| `aria-label`, `aria-labelledby` | `string`                                                                    | Имя списка. Передайте одно из них                                                                                                                                                                                                                       |

Пункты меню описывает `ContextMenuItem`: `{ id, label, icon?, hint?, danger?, disabled?, onSelect? }` или разделитель `{ type: "separator" }`.

### Клавиатура

Список целиком один элемент в порядке табуляции. Курсор показывается рамкой только при навигации с клавиатуры. Нажатия, пришедшие из элементов внутри карточки (кнопки, поля), список не перехватывает.

| Клавиша               | Действие                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `↑` / `↓`             | `vertical`: на элемент выше или ниже. `grid`: на ряд выше или ниже. В `horizontal` не действуют |
| `←` / `→`             | `grid` и `horizontal`: на соседний элемент. В `vertical` не действуют                           |
| `PageUp` / `PageDown` | На экран назад или вперёд                                                                       |
| `Home` / `End`        | Первый или последний загруженный элемент                                                        |
| `Space`               | Выбрать элемент с курсором (с `Ctrl` или `Cmd` переключает выбор)                               |
| `Enter`               | `onItemActivate` для элемента с курсором                                                        |
| `Shift+F10` / «Меню»  | Контекстное меню элемента с курсором (если задан `itemMenu`)                                    |

При фокусе на списке курсор ставится на выбранный элемент, а если выбора нет, на первый. Страница и лента подкручиваются за курсором: закреплённая шапка `Page` и плавающая панель его не закрывают.

### CSS-переменные

| Переменная             | По умолчанию            | Описание                                                                              |
| ---------------------- | ----------------------- | ------------------------------------------------------------------------------------- |
| `--list-item-radius`   | `8px`                   | Скругление строки или карточки                                                        |
| `--list-card-bg`       | `var(--elevated-bg)`    | Фон карточки в `grid` и `horizontal`                                                  |
| `--nav-safe-left`      | задаёт `NavigationView` | Ширина закрытой панелью полосы слева: на неё лента выходит под панель при `bleed`     |
| `--page-padding`       | задаёт `Page`           | Боковой отступ страницы: на него лента выходит за край при `bleed`                    |
| `--page-header-height` | задаёт `Page`           | Высота закреплённой шапки страницы: ниже неё список останавливает прокрутку к курсору |

Переменные задаются на корне списка (`className` или `style`). Последние три список только читает.

У элемента, кроме класса, есть атрибуты `data-selected` и `data-active`, а у него самого `role="option"`. Если вы рисуете карточку сами, стилизуйте по ним или по `state`.

## Быстрый старт

```tsx
import { List, Page } from "@ui-kit/components";

type Contact = { id: number; name: string; email: string };

<Page title="Контакты">
  <List
    aria-label="Контакты"
    items={contacts}
    getItemId={(c) => c.id}
    renderItem={(c) => (
      <div style={{ display: "flex", flexDirection: "column" }}>
        <strong>{c.name}</strong>
        <span style={{ color: "var(--label-secondary)" }}>{c.email}</span>
      </div>
    )}
  />
</Page>;
```

Внутри `Page` список прокручивается вместе со страницей без дополнительных обёрток. Формат меняется одним свойством: `layout="grid"` или `layout="horizontal"`.

## Примеры

### 1. Вертикальный список с выбором

```tsx
const [selectedId, setSelectedId] = useState<number | null>(null);

<List
  aria-label="Контакты"
  items={contacts}
  getItemId={(c) => c.id}
  selectable
  selectedId={selectedId}
  onSelectionChange={(id) => setSelectedId(id === null ? null : Number(id))}
  onItemActivate={(c) => navigate(`/contacts/${c.id}`)}
  renderItem={(c) => (
    <div
      style={{ display: "flex", alignItems: "center", gap: 12, width: "100%" }}
    >
      <Avatar name={c.name} />
      <span style={{ flex: 1 }}>{c.name}</span>
    </div>
  )}
/>;
```

Клик выбирает контакт, `Enter` или двойной клик открывает его. Для неуправляемого режима достаточно `defaultSelectedId`.

### 2. Сетка карточек

```tsx
<List
  aria-label="Фотографии"
  layout="grid"
  items={photos}
  getItemId={(p) => p.id}
  itemWidth={220}
  itemAspectRatio={4 / 3}
  gap={16}
  selectable
  renderItem={(p) => (
    <>
      <img
        src={p.url}
        alt=""
        style={{ flex: 1, minHeight: 0, width: "100%", objectFit: "cover" }}
      />
      <div style={{ padding: "8px 12px" }}>{p.title}</div>
    </>
  )}
/>
```

Число столбцов считается по ширине: `itemWidth` задаёт наименьшую ширину карточки, лишнее место делят все карточки ряда. Хотите ровно четыре столбца при любой ширине, задайте `columns={4}`. С `itemAspectRatio` высота карточки следует за её шириной, поэтому подпись входит в эти пропорции.

### 3. Горизонтальная лента под плавающей панелью

Лента всегда прокручивается внутри себя. При `extendContentUnderPane` у `NavigationView` она тянется до левого края окна, первая карточка стоит там же, где стояла, а при прокрутке карточки уходят под размытую панель.

```tsx
<NavigationView extendContentUnderPane menuItems={/* … */}>
  <Page title="Главная">
    <h2 className="SubtitleTextBlockStyle">Недавние</h2>
    <List
      aria-label="Недавние"
      layout="horizontal"
      items={recent}
      getItemId={(d) => d.id}
      itemWidth={180}
      itemHeight={220}
      onItemActivate={(d) => open(d)}
      renderItem={(d) => <DocumentTile document={d} />}
    />
  </Page>
</NavigationView>;

// не уходить под панель: лента остаётся в безопасной области
<List layout="horizontal" bleed={false} … />
```

Вертикальное колесо мыши ленту не прокручивает (это поведение браузера): работают `Shift` + колесо, жест трекпада, перетаскивание полосы прокрутки и клавиши `←` и `→`.

### 4. Бесконечная подгрузка

```tsx
const PAGE_SIZE = 40;

function CitiesPage() {
  const [query, setQuery] = useState("");
  const [items, setItems] = useState<City[]>([]);
  const [total, setTotal] = useState<number>();
  const [hasMore, setHasMore] = useState(true);
  const [loading, setLoading] = useState(false);
  const [failed, setFailed] = useState(false);
  const request = useRef(0);

  const loadPage = useCallback(async (offset: number, q: string) => {
    const id = ++request.current;
    setLoading(true);
    setFailed(false);
    try {
      const page = await api.cities({ q, offset, limit: PAGE_SIZE });
      if (id !== request.current) return;
      setItems((prev) =>
        offset === 0 ? page.items : [...prev, ...page.items],
      );
      setTotal(page.total);
      setHasMore(offset + page.items.length < page.total);
    } catch {
      if (id === request.current) setFailed(true);
    } finally {
      if (id === request.current) setLoading(false);
    }
  }, []);

  useEffect(() => {
    void loadPage(0, query);
  }, [query, loadPage]);

  return (
    <Page
      title="Города"
      toolbar={{
        trailing: <SearchField onChange={(e) => setQuery(e.target.value)} />,
      }}
    >
      <List
        aria-label="Города"
        layout="grid"
        items={items}
        getItemId={(c) => c.id}
        hasMore={hasMore}
        loadingMore={loading}
        loadMoreError={failed}
        onEndReached={() => void loadPage(items.length, query)}
        totalCount={total}
        resetKey={query}
        emptyContent="Ничего не найдено"
        renderItem={(c) => <CityCard city={c} />}
      />
    </Page>
  );
}
```

Список сам решает, когда просить следующую порцию, и не вызывает `onEndReached` повторно, пока идёт загрузка, пока показана ошибка или пока число элементов не изменилось. При ошибке в конце появляются сообщение и кнопка «Повторить», которая вызывает `onEndReached` снова. Новый поисковый запрос меняет `resetKey`: список возвращается к началу. Счётчик `request` отбрасывает устаревшие ответы. Подгрузка работает так же в `vertical` и `horizontal` (в ленте кольцо загрузки стоит за последней карточкой).

### 5. Контекстное меню

```tsx
<List
  aria-label="Документы"
  items={documents}
  getItemId={(d) => d.id}
  selectable
  itemMenu={({ item }) =>
    item.readonly
      ? null // меню браузера
      : [
          {
            id: "open",
            label: "Открыть",
            icon: <OpenIcon />,
            hint: "Enter",
            onSelect: () => open(item),
          },
          {
            id: "rename",
            label: "Переименовать",
            onSelect: () => rename(item),
          },
          { type: "separator" },
          {
            id: "delete",
            label: "Удалить",
            danger: true,
            onSelect: () => remove(item),
          },
        ]
  }
  renderItem={(d) => <DocumentRow document={d} />}
/>
```

Меню открывается правой кнопкой, `Shift+F10` или клавишей «Меню». Элемент, на котором открыли меню, выбирается (при `selectable`), а при закрытии фокус возвращается на список. Если элемент пропал из `items`, пока меню открыто, меню закрывается.

### 6. Свои карточки

`renderItem` получает элемент и его состояние. При `itemAppearance="default"` список рисует строку или карточку и подсвечивает наведение, выбор и курсор, вам остаётся содержимое. Если нужна полностью своя рамка, отключите её и стилизуйте по `state` или по атрибутам `data-selected` и `data-active`:

```tsx
import type { ListItemState } from "@ui-kit/components";

function ProductCard({
  product,
  state,
}: {
  product: Product;
  state: ListItemState;
}) {
  return (
    <div
      className={styles.card}
      data-selected={state.selected || undefined}
      data-active={state.active || undefined}
    >
      <img className={styles.cover} src={product.image} alt="" />
      <div className={styles.title}>{product.title}</div>
      <Button
        onClick={(e) => {
          e.stopPropagation(); // не выбирать карточку и не вызывать onItemClick
          addToCart(product);
        }}
      >
        В корзину
      </Button>
    </div>
  );
}

<List
  aria-label="Товары"
  layout="grid"
  itemAppearance="none"
  selectable
  items={products}
  getItemId={(p) => p.id}
  itemWidth={240}
  itemHeight={320}
  renderItem={(p, state) => <ProductCard product={p} state={state} />}
/>;
```

```css
.card {
  height: 100%;
  border-radius: 16px;
  background: var(--elevated-bg);
  box-shadow: inset 0 0 0 1px var(--separator);
}
.card[data-selected] {
  box-shadow: inset 0 0 0 2px var(--control-accent);
}
.card[data-active] {
  outline: 2px solid var(--keyboard-focus-indicator);
  outline-offset: -2px;
}
```

Обёртка элемента задаёт размер (`itemWidth`, `itemHeight`) и обрезает содержимое, поэтому карточка должна занимать его целиком (`height: 100%`).

### 7. Список и подробности рядом

```tsx
const [selectedId, setSelectedId] = useState<number | null>(null);
const selected = messages.find((m) => m.id === selectedId) ?? null;

<div
  style={{
    display: "grid",
    gridTemplateColumns: "340px 1fr",
    gap: 24,
    alignItems: "start",
  }}
>
  <List
    aria-label="Сообщения"
    height={560}
    items={messages}
    getItemId={(m) => m.id}
    selectable
    selectedId={selectedId}
    onSelectionChange={(id) => setSelectedId(id === null ? null : Number(id))}
    itemHeight={72}
    renderItem={(m) => <MessagePreview message={m} />}
  />
  {selected ? <MessageView message={selected} /> : <p>Выберите сообщение</p>}
</div>;
```

С фиксированной `height` список прокручивается внутри себя и не зависит от прокрутки страницы. Подгрузка и клавиатура работают так же.

### 8. Переключение формата

Один набор данных можно показывать в разных форматах. `state.layout` подсказывает карточке, каким видом рисоваться.

```tsx
const [layout, setLayout] = useState<ListLayout>("grid");

<>
  <ToolbarGroup>
    <ToolbarButton
      icon={<GridIcon />}
      aria-label="Сетка"
      onClick={() => setLayout("grid")}
    />
    <ToolbarButton
      icon={<ListIcon />}
      aria-label="Список"
      onClick={() => setLayout("vertical")}
    />
  </ToolbarGroup>

  <List
    aria-label="Файлы"
    layout={layout}
    items={files}
    getItemId={(f) => f.id}
    itemWidth={200}
    itemHeight={layout === "vertical" ? 48 : 180}
    renderItem={(f, state) =>
      state.layout === "vertical" ? <FileRow file={f} /> : <FileTile file={f} />
    }
  />
</>;
```

При смене `layout` список прокручивается к началу и забывает курсор клавиатуры. Выбранный элемент остаётся выбранным, потому что хранится по id.

## Ограничения

- Все элементы одного размера: переменная высота строк, переменная ширина карточек и «кирпичная» раскладка не поддерживаются.
- Выбирается только один элемент. Множественного выбора, выбора диапазона и `Ctrl+A` нет.
- Нет группировки с заголовками, дерева, перетаскивания, перестановки элементов, свайпов и перевёрнутого списка для чатов.
- Появление и исчезновение элементов не анимируется.
- Список рассчитан на раскладку слева направо: в режиме «справа налево» позиции карточек и клавиши `←` и `→` не зеркалятся.
- `getItemId` должен возвращать стабильный уникальный id: по нему отслеживаются выбор, курсор и открытое меню. `items` должен быть новым массивом при каждом изменении данных, иначе id не пересчитаются.
- Содержимое элемента обрезается по его границам. Если карточка выше, чем `itemHeight`, лишнее не видно.
- Клик по любому месту элемента, в том числе по кнопке внутри карточки, выбирает его и вызывает `onItemClick`. Чтобы отдельная кнопка в карточке не выбирала элемент, остановите всплытие (`e.stopPropagation()`). Нажатия клавиш внутри карточки список игнорирует, а сам элемент объявляется скринридеру как `option`, поэтому насыщенные интерактивные карточки с несколькими кнопками доступны хуже простых.
- `height` не используется в `horizontal`: высота ленты равна `itemHeight`. `bleed` работает только в `horizontal`, у `vertical` и `grid` такого выхода под панель нет.
- Выход под панель берёт отступы из `--nav-safe-left` и `--page-padding`. Вне `NavigationView` и `Page` обе переменные равны нулю, и лента остаётся в границах контейнера.
- Прокрутка со страницей ищет ближайшего предка с `overflow-y: auto`, `scroll` или `overlay`, иначе прокручивает окно. Предок с `overflow: hidden` между списком и областью прокрутки обрежет список.
- Закреплённая шапка `Page` учитывается только при прокрутке к курсору клавиатуры и контекстному меню. Закреплённые элементы других компонентов список не знает.
- Контекстное меню рисуется порталом в `<body>`, закрывается при любой прокрутке и не наследует CSS-переменные списка.
