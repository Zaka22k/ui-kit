# DataGrid

Таблица для просмотра длинных списков: строки виртуализированы, ширину колонок можно менять, строки можно выделять, а следующая порция данных запрашивается, когда пользователь доходит до конца.

## Свойства

Таблица ничего не загружает, не сортирует и не фильтрует сама: данные, загрузку, ошибки, поиск и сортировку ведёт родитель, а таблица показывает переданные `rows`. Передайте `aria-label` или `aria-labelledby`.

### DataGrid

| Свойство                        | Тип                                                  | Описание                                                                                                                                                                                                                                                      |
| ------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rows`                          | `readonly T[]`                                       | Загруженные на данный момент строки                                                                                                                                                                                                                           |
| `columns`                       | `readonly DataGridColumn<T>[]`                       | Описание колонок, см. ниже                                                                                                                                                                                                                                    |
| `getRowId`                      | `(row) => string \| number`                          | Стабильный уникальный id строки. К нему привязаны выделение и анимации. Читается при смене `rows`, а не при каждом рендере                                                                                                                                    |
| `height`                        | `number \| string`                                   | По умолчанию `"auto"`: таблица прокручивается вместе со страницей. Число или `"100%"`: таблица прокручивается внутри себя в контейнере этой высоты                                                                                                              |
| `stickyTop`                     | `number \| string`                                   | Отступ сверху (px или CSS-значение) для прилипшей шапки при прокрутке со страницей. По умолчанию высота шапки `Page` (`--page-header-height`, 68px), вне `Page` `64px`                                                                                         |
| `bleed`                         | `boolean`                                            | При прокрутке со страницей таблица тянется до края окна, и горизонтальная прокрутка уходит под плавающую панель `NavigationView` (`extendContentUnderPane`). По умолчанию `true`. Вне `NavigationView` и `Page` ничего не меняет                                  |
| `striped`                       | `boolean`                                            | Чередующаяся заливка строк вместо разделителей. По умолчанию `false`                                                                                                                                                                                          |
| `emptyContent`                  | `ReactNode`                                          | Что показать, когда строк нет. По умолчанию «Нет данных»                                                                                                                                                                                                      |
| `selectable`                    | `boolean`                                            | Колонка с чекбоксами. Shift+клик по чекбоксу выделяет диапазон, `Space` переключает строку с курсором, `Ctrl+A` выделяет все загруженные строки. Клик по самой строке выделение не меняет. По умолчанию `false`                                                  |
| `selectedIds`                   | `ReadonlySet<string \| number>`                      | Выделенные id (управляемый режим)                                                                                                                                                                                                                              |
| `defaultSelectedIds`            | `Iterable<string \| number>`                         | Выделенные id в начале (неуправляемый режим)                                                                                                                                                                                                                   |
| `onSelectionChange`             | `(ids: ReadonlySet<string \| number>) => void`       | Выделение изменилось. Приходит новый `Set`                                                                                                                                                                                                                     |
| `onRowClick`                    | `(row) => void`                                      | Клик по строке                                                                                                                                                                                                                                                 |
| `onRowActivate`                 | `(row) => void`                                      | Двойной клик или `Enter` на строке с курсором                                                                                                                                                                                                                  |
| `hasMore`                       | `boolean`                                            | На сервере есть ещё данные. По умолчанию `false`                                                                                                                                                                                                               |
| `loadingMore`                   | `boolean`                                            | Идёт подгрузка: в конце списка кольцо загрузки. По умолчанию `false`                                                                                                                                                                                           |
| `loadMoreError`                 | `boolean`                                            | Подгрузка упала: в конце сообщение и кнопка «Повторить», она снова вызывает `onEndReached`. По умолчанию `false`                                                                                                                                               |
| `onEndReached`                  | `() => void`                                         | Пора загрузить следующую порцию. Вызывается, когда до конца загруженных строк осталось не больше `endReachedThreshold` строк, при `hasMore`, без `loadingMore` и `loadMoreError`. Если строк не хватает, чтобы заполнить экран, вызывается автоматически       |
| `endReachedThreshold`           | `number`                                             | За сколько строк до конца вызывается `onEndReached`. По умолчанию `10`                                                                                                                                                                                          |
| `totalCount`                    | `number`                                             | Всего строк на сервере, только для скринридеров                                                                                                                                                                                                                |
| `resetKey`                      | `string \| number`                                   | Смените, когда список заменён целиком (поиск, сортировка): таблица прокрутится к началу и не будет анимировать замену                                                                                                                                          |
| `rowMenu`                       | `(target) => ContextMenuItem[] \| null \| undefined` | Пункты контекстного меню строки. `target` содержит `row` (строка, на которой открыли меню) и `rows` (все выделенные строки, если строка выделена, иначе только `row`). Если ничего не вернуть, останется меню браузера. Открывается правой кнопкой, `Shift+F10` или клавишей «Меню» |
| `animateChanges`                | `boolean`                                            | Анимировать появление и исчезновение строк (до 20 изменений за раз). По умолчанию `true`                                                                                                                                                                       |
| `className`, `style`            |                                                      | Корневой элемент                                                                                                                                                                                                                                               |
| `aria-label`, `aria-labelledby` | `string`                                             | Имя таблицы. Передайте одно из них                                                                                                                                                                                                                             |

### DataGridColumn

| Свойство    | Тип                                  | Описание                                                                                         |
| ----------- | ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `id`        | `string`                             | Идентификатор колонки, уникален в таблице                                                        |
| `header`    | `ReactNode`                          | Содержимое заголовка                                                                             |
| `cell`      | `(row: T, index: number) => ReactNode` | Содержимое ячейки. Текст обрезается многоточием и не переносится                               |
| `width`     | `number`                             | Начальная ширина, px. По умолчанию `160`                                                         |
| `minWidth`  | `number`                             | Наименьшая ширина, px. По умолчанию `80`                                                         |
| `maxWidth`  | `number`                             | Наибольшая ширина, px                                                                            |
| `resizable` | `boolean`                            | Можно ли менять ширину. По умолчанию `true`                                                      |
| `align`     | `"start" \| "center" \| "end"`       | Выравнивание заголовка и ячеек. По умолчанию `"start"`                                           |

Ширину колонки меняют мышью (потянуть правый край заголовка) или с клавиатуры: `Tab` до ручки, затем `←` и `→` меняют ширину на 10px, с `Shift` на 50px. Последняя колонка растягивается на всё свободное место.

### Клавиатура

| Клавиша               | Действие                                                    |
| --------------------- | ----------------------------------------------------------- |
| `↑` / `↓`             | Курсор на строку выше или ниже, страница подкручивается     |
| `PageUp` / `PageDown` | Курсор на экран вверх или вниз                              |
| `Home` / `End`        | Первая или последняя загруженная строка                     |
| `Space`               | Выделить или снять выделение (при `selectable`)             |
| `Enter`               | `onRowActivate` для строки с курсором                       |
| `Ctrl+A` / `Cmd+A`    | Выделить все загруженные строки (при `selectable`)          |
| `Shift+F10` / «Меню»  | Контекстное меню строки (если задан `rowMenu`)              |

### CSS-переменные

| Переменная                  | По умолчанию                    | Описание                                                                                                            |
| --------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `--DataGridStickyTop`       | `64px`                          | Отступ прилипшей шапки сверху. Вне `Page`; внутри `Page` берётся `--page-header-height`                             |
| `--DataGridHeaderBackground` | `var(--sticky-header-bg)`      | Фон шапки таблицы. Вне `Page` запасное значение `--material-header-bg`; при внутренней прокрутке `--window-bg`      |
| `--sticky-header-bg`        | задаёт `Page`                   | Общий фон шапки страницы и шапки таблицы                                                                            |
| `--sticky-header-filter`    | задаёт `Page`                   | Общий блюр шапки страницы и шапки таблицы. Вне `Page` запасное значение `--material-blur`                           |
| `--page-header-height`      | задаёт `Page`                   | Высота шапки страницы: по ней шапка таблицы липнет вплотную                                                         |
| `--page-padding`            | задаёт `Page`                   | Боковой отступ страницы: на него таблица выходит за край при `bleed`                                                |
| `--nav-safe-left`           | задаёт `NavigationView`         | Ширина закрытой панелью полосы слева: на неё таблица выходит под панель при `bleed`                                 |

## Быстрый старт

```tsx
import { DataGrid, Page } from "./components";
import type { DataGridColumn } from "./components";

type City = { id: number; name: string; country: string; population: number };

const columns: DataGridColumn<City>[] = [
  { id: "name", header: "Город", cell: (c) => c.name, width: 240 },
  { id: "country", header: "Страна", cell: (c) => c.country },
  {
    id: "population",
    header: "Население",
    cell: (c) => c.population,
    align: "end",
  },
];

// Внутри Page таблица прокручивается вместе со страницей без дополнительных обёрток
<Page title="Города">
  <DataGrid
    aria-label="Города"
    columns={columns}
    getRowId={(c) => c.id}
    rows={cities}
  />
</Page>;
```

## Примеры

### 1. Два режима прокрутки

```tsx
// по умолчанию: прокрутка со страницей
// шапка прилипает под шапкой страницы, строки проходят под ней
<DataGrid rows={rows} columns={columns} getRowId={(r) => r.id} aria-label="Записи" />

// внутренняя прокрутка: таблица в контейнере фиксированной высоты
<DataGrid height={480} rows={rows} columns={columns} getRowId={(r) => r.id} aria-label="Записи" />
<DataGrid height="100%" rows={rows} columns={columns} getRowId={(r) => r.id} aria-label="Записи" />
```

При прокрутке со страницей таблица находит ближайший прокручиваемый контейнер (область страницы `NavigationView`, тело `Modal` или `window`) и виртуализирует строки относительно него. Внутри `Page` шапка таблицы и шапка страницы имеют один фон и один блюр: пока шапка таблицы прилипла, подложку за обе рисует шапка страницы, поэтому на стыке нет шва. При внутренней прокрутке шапка прилипает к верху самой таблицы и имеет непрозрачный фон.

### 2. Выделение и действие над выбранными строками

Строки виртуализированы, поэтому выделенные id передаются через скрытые поля формы:

```tsx
const [selected, setSelected] = useState<ReadonlySet<DataGridRowId>>(new Set());
const [state, formAction, isPending] = useActionState(deleteRowsAction, null);

<form action={formAction}>
  {Array.from(selected).map((id) => (
    <input key={id} type="hidden" name="selectedIds" value={String(id)} />
  ))}
  <Button
    type="submit"
    appearance="destructive"
    disabled={selected.size === 0 || isPending}
  >
    Удалить выбранные ({selected.size})
  </Button>
</form>

<DataGrid
  selectable
  selectedIds={selected}
  onSelectionChange={setSelected}
  rows={rows}
  columns={columns}
  getRowId={(r) => r.id}
  aria-label="Список записей"
/>
```

Когда действие удаляет или добавляет до 20 строк, таблица плавно сдвигает соседние строки и подсвечивает новые записи акцентным цветом.

### 3. Бесконечная прокрутка

```tsx
<DataGrid
  rows={rows}
  columns={columns}
  getRowId={(r) => r.id}
  hasMore={hasMore}
  loadingMore={loading}
  loadMoreError={failed}
  onEndReached={loadNext}
  endReachedThreshold={10}
  totalCount={total}
  aria-label="Записи"
/>
```

При ошибке подгрузки в конце списка появится сообщение и кнопка «Повторить», которая снова вызовет `onEndReached`.

### 4. Поиск и сортировка

Поиск и сортировку выполняет родитель. Когда список заменён целиком, меняйте `resetKey`: таблица прокрутится к началу и не будет анимировать замену.

```tsx
const [query, setQuery] = useState("");
const [sort, setSort] = useState<"name" | "date">("name");

const visible = useMemo(
  () => sortRows(filterRows(rows, query), sort),
  [rows, query, sort],
);

<Page title="Записи" toolbar={{ trailing: <SearchField onChange={(e) => setQuery(e.target.value)} /> }}>
  <DataGrid
    rows={visible}
    columns={columns}
    getRowId={(r) => r.id}
    resetKey={`${query}|${sort}`}
    emptyContent="Ничего не найдено"
    aria-label="Записи"
  />
</Page>;
```

### 5. Контекстное меню строки

```tsx
<DataGrid
  rows={rows}
  columns={columns}
  getRowId={(r) => r.id}
  selectable
  rowMenu={({ row, rows }) => [
    { id: "open", label: "Открыть", icon: <OpenIcon />, onSelect: () => open(row) },
    { id: "copy", label: "Копировать", hint: "Ctrl+C", onSelect: () => copy(rows) },
    { type: "separator" },
    { id: "delete", label: "Удалить", danger: true, onSelect: () => remove(rows) },
  ]}
  aria-label="Записи"
/>
```

Меню рисуется порталом в `<body>`. При выборе пункта фокус возвращается на таблицу до вызова `onSelect`, поэтому `Modal`, открытый из `onSelect`, при закрытии вернёт фокус на таблицу. При `selectable` правый клик по невыделенной строке выделяет её.

### 6. Полосатая таблица

```tsx
<DataGrid striped rows={rows} columns={columns} getRowId={(r) => r.id} aria-label="Расписание" />
```

Разделителей между строками нет, строки различаются заливкой.

### 7. Таблица под плавающей боковой панелью

Если у `NavigationView` включён `extendContentUnderPane`, горизонтальная прокрутка широкой таблицы уходит под панель: таблица тянется до края окна, а первая колонка стоит там же, где стояла.

```tsx
<NavigationView extendContentUnderPane menuItems={/* … */}>
  <Page title="Журнал успеваемости">
    <DataGrid
      rows={students}
      columns={wideColumns}
      getRowId={(s) => s.id}
      aria-label="Журнал"
    />
  </Page>
</NavigationView>

// отключить: таблица остаётся в безопасной области
<DataGrid bleed={false} … />
```

### 8. Таблица вне `Page`

Вне `Page` переменных страницы нет, поэтому задайте отступ шапки сами:

```tsx
// отступ прилипшей шапки
<DataGrid stickyTop={48} … />
<DataGrid stickyTop="var(--toolbar-height)" … />

// фон шапки
<DataGrid style={{ "--DataGridHeaderBackground": "var(--control-bg)" } as React.CSSProperties} … />
```

## Ограничения

- Таблица только для просмотра: нет редактирования ячеек, сортировки по клику на заголовок, фильтрации, перестановки и скрытия колонок.
- Высота строки и шапки фиксирована (40px). Текст в ячейках не переносится и обрезается многоточием.
- Ширина колонок, изменённая пользователем, хранится внутри компонента и сбрасывается при его повторном монтировании.
- `getRowId` должен возвращать стабильный уникальный id: по нему отслеживаются выделение, курсор и анимации. `rows` должен быть новым массивом при каждом изменении данных.
- Выделение и `Ctrl+A` работают только по загруженным строкам. Строки, которых ещё нет в `rows`, выделить нельзя.
- Анимируются изменения до 20 строк за раз, при бо́льшем числе строки заменяются без анимации.
- Прилипание шапки (`position: sticky`) не сработает, если между таблицей и областью прокрутки страницы есть предок с `overflow: hidden`, `auto` или `scroll`.
- Общий с шапкой страницы фон и блюр работают только внутри `Page` (через `PageStickyContext`). Вне `Page` у шапки таблицы свой фон и блюр, и если рядом есть другая липкая шапка, стык между ними может быть виден.
- `bleed` работает только при прокрутке со страницей (`height="auto"`). При фиксированной высоте таблица остаётся в границах контейнера.
- Ячейки, ушедшие под плавающую панель при горизонтальной прокрутке, недоступны для клика: панель лежит выше.
- Размытие шапки зависит от `backdrop-filter`. Без его поддержки остаётся полупрозрачный фон без размытия.
- Контекстное меню рендерится порталом в `<body>` и не наследует CSS-переменные таблицы.
